# Smart Notes Server with AI Integration

This is the backend server for the Smart Notes application, featuring AI-powered summarization and tagging capabilities.

## Setup Instructions

1. Install dependencies:
```bash
npm install
```

2. Create a `.env` file in the server directory with the following variables:
```
PORT=3000
MONGODB_URI=mongodb://localhost:27017/smart-notes
OPENAI_API_KEY=your_openai_api_key
JWT_SECRET=smart-notes-secret-key-2024
```
